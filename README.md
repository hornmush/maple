# MVP LAB

엘리시움 메이플스토리 MVP작 효율 계산기 프로젝트.

## 개발 목표
1. 간편 계산기: 충전 수단별 할인율, 메소 시세, 경매장 수수료 반영
2. 물품 효율 순위표: 판매가 입력 및 회수율 비교
3. 크레딧샵: 메이플 크레딧 사용 효율 비교
4. 엘리시움 경매장 시세 연동: 외부 데이터 수집의 이용약관 및 안정성 검증 후 추가

## 시세 연동 주의
넥슨 공식 Open API의 경매장 가격 조회 기능은 확인되지 않았습니다.
Maple Auction MCP는 일반 공개 HTTP API가 아니므로 Vercel 서버에서 직접 호출할 수 있다고 가정하지 않습니다.
인증 쿠키나 로그인 정보를 Supabase/브라우저 공개 코드에 저장하지 마세요.

## 상태
초기 저장소 준비. 기존 MVP LAB HTML 이전 및 Vercel 배포 설정 예정.
